# Prompt — Rascunho de entrega (workflow 02)

Vive no Code node "Prepare Exec". Aciona por `/exec <descrição>` no Telegram.

Diretrizes:
- Produz a **entrega em si**, não uma proposta.
- Marca com `[VERIFICAR]` tudo que depende de dado que a IA não tem, para você conferir.
- Sempre volta para **sua revisão** antes de ir ao cliente (regra da camada Guard).
