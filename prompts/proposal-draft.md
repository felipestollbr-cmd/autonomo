# Prompt — Rascunho de proposta (workflow 01)

Este texto vive dentro do Code node "Score & Draft Prompt". Ajuste lá.

Diretrizes que o prompt impõe:
- Escreve em inglês, até ~130 palavras, tom direto e confiante.
- Abre mostrando que entendeu o problema específico do cliente.
- Cita 1 resultado concreto entregável.
- Fecha com pergunta aberta.
- **Não inventa histórico falso** — fala de capacidade, não de experiências fabricadas.

Por que isso importa: proposta honesta protege sua reputação. O agente rascunha;
**você** revisa e se candidata na fonte. Nada é enviado automaticamente.
